# BLOOM GLOW 达人端 H5 demo

达人从收到授权链接，到日常查看排期和带货数据的 10 屏可点击原型（静态页面，无后端）。

- 总览：打开首页，10 屏并排展示
- 逐屏体验：首页地址后加 `?screen=s1`，一屏一屏点击（电脑上以手机尺寸居中显示）
- 中文版：`zh.html`（内部演示用，由 `make_zh.py` 从英文版生成；改英文版后重新运行）

页面中的账号、商品、金额均为示意数据；TikTok 授权页按官方开发文档截图示意，以实际页面为准。

## 运营后台「分发」页（演示）

`ops.html`：在带货车间侧栏「账号」下面新增「分发」。把制作交付的成片和它挂的商品，分给一个已授权的达人号，填发布时间和文案，提交前逐项检查（授权、当天条数、橱窗、库存、时间、文案、10MB、走哪条路发），运营确认后到点经 API 自动发，链接和数据写回分发单。

- https://uni-jy.github.io/bloomglow-h5-demo/ops.html
- `?view=new` 直接打开新建分发；`?view=job:D-1125-014` 打开一条预审不过的单；`?view=tab:sched` 打开已排期
